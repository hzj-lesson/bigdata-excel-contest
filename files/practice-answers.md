## 一、大题一：销售数据统计（素材：销售数据统计-练习素材.xlsx）

### 任务回顾
1. 基础处理：日期列 yyyy-mm-dd 居中；数量/单价数值格式右对齐；表头深蓝底白字加粗；数据区细边框。
2. 新增"销售额"=数量×单价(0位)、"销售提成"用 IF 阶梯：≥10万→5%，5万~10万→3%，<5万→1.5%(2位)。
3. 统计行：总数量、平均单价(1位)、总销售额、总提成(2位)。
4. 筛选"华北 且 销售额≥80000"复制到 Sheet2。
5. 透视表：行=销售区域、列=产品名称、值=销售数量(求和)+销售额(求和)；回答"哪个区域总销售额最高"。
6. 图表：各区域销售额对比柱形图（设标题/坐标轴/图例）。

### 标准答案（校验值）
- 总销售数量 = **532**
- 平均单价 = **4869.4** 元
- 总销售额 = **2,590,500** 元
- 总提成 = **103,803.0** 元
- 销售额最高的区域 = **华北**（1,069,100 元）
- "华北 且 ≥80000" 的记录共 **8** 条（复制到 Sheet2 应正好这么多行）
- 分产品销售额（透视表可交叉核对）：笔记本电脑 1,209,000元；智能手机 949,500元；平板电脑 432,000元
- 月度销售额趋势（若做折线图应看到）：2026-01 353,600元；2026-02 361,200元；2026-03 499,100元；2026-04 429,000元；2026-05 481,000元；2026-06 466,600元
- 提成阶梯抽查 3 行：销售额 100000+ → ×5%；50000~99999 → ×3%；<50000 → ×1.5%，用 ROUND 保留 2 位。
